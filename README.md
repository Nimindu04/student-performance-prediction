# Student Performance Prediction using Machine Learning

## Overview

This project predicts students' final exam grades using
academic and behavioral features.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models

- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## Workflow

1. Data collection
2. Data preprocessing
3. Exploratory data analysis
4. Feature selection
5. Train-test split
6. Model training
7. Model evaluation
8. Model comparison
9. Student grade prediction

## Evaluation Metrics

- MAE
- RMSE
- R² Score

## Results

The models were evaluated using an 80/20 train-test split.
The results are reported in the notebook.

## Future Improvements

- Hyperparameter tuning
- Cross-validation
- More student data
- Classification of students into performance categories
- Web-based prediction interface
